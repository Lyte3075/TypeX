# TypeX ⌨️

TypeX is a customizable iOS keyboard project focused on expressive layouts, themes, and a clean native experience.

## Project status

🚧 Early development.

The repository currently contains the initial project architecture and keyboard-extension source. The Xcode project/target is generated during the Apple build step because iOS keyboard extensions require an app target plus a Keyboard Extension target.

## Architecture

- **TypeXApp**: main app for keyboard settings and customization
- **TypeXKeyboard**: iOS Custom Keyboard Extension
- **Shared**: models/configuration shared by the app and extension
